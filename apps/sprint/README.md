# DIASMATH Sprint

Aplicação independente do DIASMATH para criação e aplicação de atividades matemáticas ao vivo.

## Infraestrutura

- GitHub: código-fonte
- Vercel: hospedagem
- Supabase: autenticação, banco, realtime e storage
- Sem dependência de créditos do Lovable

## Recursos

- Professor com login por e-mail/senha e Google OAuth via Supabase
- Criação e edição de atividades
- Questões com imagens
- Sessões ao vivo com PIN e QR Code
- Participantes sem cadastro com escolha de personagem
- Ranking e resultados
- Importação de PDF/DOCX com revisão antes de salvar

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
