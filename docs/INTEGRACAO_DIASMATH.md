# Integração ao DIASMATH

Adicione na aba Professor um botão apontando para:

```html
<a href="/professor/forms/index.html">DIASMATH Forms</a>
```

Envie a pasta completa para:

```text
/professor/forms/
```

Não envie apenas o `index.html`; mantenha as pastas `css` e `js`.

Para versão online multiusuário, preserve as telas e substitua somente os métodos de `js/storage.js`.
