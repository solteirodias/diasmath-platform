# SAP V15 — IA responde qualquer pergunta do SAP

## Correção feita

A pergunta personalizada não fica mais presa a um modelo fixo.

A IA agora interpreta a intenção da pergunta e responde diretamente.

## Exemplos

Pergunta:

```text
Quais foram os melhores resultados?
```

Resposta esperada:

```text
Os melhores resultados do recorte aparecem...
```

Pergunta:

```text
Quais habilidades devo priorizar?
```

Resposta esperada:

```text
As maiores prioridades do recorte são...
```

Pergunta:

```text
Como melhorar o desempenho dos estudantes em Matemática?
```

Resposta esperada:

```text
Para melhorar o desempenho em Matemática...
```

## Intenções reconhecidas

- melhores resultados;
- piores resultados;
- prioridades;
- comparação;
- ranking;
- plano de intervenção;
- orientação aos professores;
- devolutiva;
- mensagem para escola;
- orientação para gestão/GRE;
- perguntas amplas sobre uso pedagógico dos dados.
