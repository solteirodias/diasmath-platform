# Casos trabalhados

## Duas raízes reais

- `x² + 5x + 6 = 0`
- `2x² + 7x + 3 = 0`

O retângulo dos fatores possui dois lados que podem ser anulados em valores diferentes.

## Uma raiz real

- `x² + 4x + 4 = 0`
- `4x² + 4x + 1 = 0`

Os dois fatores conduzem ao mesmo valor de `x`.

## Nenhuma raiz real

- `x² + 2x + 5 = 0`
- `2x² + 4x + 7 = 0`

Ao completar a organização quadrada, ainda resta uma área positiva. Por isso, a construção não atinge zero no conjunto dos números reais.
