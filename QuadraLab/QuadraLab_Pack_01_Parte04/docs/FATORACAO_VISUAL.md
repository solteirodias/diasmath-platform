# Fatoração visual no QuadraLab

O QuadraLab não utiliza a fórmula de Bhaskara.

A investigação segue este fluxo:

1. representar `ax² + bx + c` com peças;
2. decompor o termo linear em duas parcelas;
3. organizar quatro regiões de área;
4. formar um retângulo;
5. ler os dois lados algébricos;
6. usar a ideia de que uma área igual a zero exige que um dos lados seja zero.

## Exemplo com `a = 1`

```text
x² + 5x + 6
```

As peças podem formar um retângulo com lados:

```text
x + 2
x + 3
```

## Exemplo com `a ≠ 1`

```text
2x² + 7x + 3
```

O termo central pode ser decomposto em:

```text
6x + x
```

As quatro regiões recompõem:

```text
2x² + 6x + x + 3
```

O retângulo revela os fatores lineares.

## Casos sem fatoração inteira

Quando a montagem retangular inteira não fecha, o laboratório conduz o estudante à reorganização por completamento de quadrado. O objetivo continua sendo manipular e compreender, não aplicar uma fórmula pronta.
