# Atalhos do laboratório

| Ação | Atalho |
|---|---|
| Seleção múltipla | Shift + clique |
| Girar peça x | R |
| Trocar sinal | N |
| Duplicar | Ctrl/Cmd + D |
| Excluir | Delete ou Backspace |
| Desfazer | Ctrl/Cmd + Z |
| Refazer | Ctrl/Cmd + Y ou Ctrl/Cmd + Shift + Z |
| Limpar seleção | Esc |
| Mover uma casa | Setas |
