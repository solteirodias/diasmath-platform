# Integração ao DIASMATH

O QuadraLab é uma aplicação Vite independente.

## Opção 1 — Subpasta estática

Publique a pasta `dist/` em:

```text
/labs/quadralab/
```

Crie um card no DIASMATH apontando para:

```text
/labs/quadralab/index.html
```

## Opção 2 — GitHub Pages separado

Publique o QuadraLab em um repositório próprio e utilize o endereço gerado pelo GitHub Pages.
