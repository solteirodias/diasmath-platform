## Como subir no GitHub

1. Baixe o ZIP.
2. Extraia o ZIP.
3. No GitHub, clique em **Add file → Upload files**.
4. Envie as pastas extraídas:

```text
public
docs
```

5. Commit sugerido:

```text
Atualiza SAP com dados do 5º Miniteste
```

6. Aguarde a Vercel publicar.
